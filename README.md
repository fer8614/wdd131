# WDD 131

Course work and practice projects for BYU-Idaho WDD 131 - Dynamic Web Fundamentals.

## Project Structure

- `index.html` - home page with the course layout, profile, and resource links.
- `temples.html` - responsive temple album with mobile navigation and a responsive image gallery.
- `styles/` - shared and page-specific CSS files.
- `scripts/` - JavaScript used for dates and interactive behavior.
- `week01/` and `week02/` - practice exercises and layout demos.

## Preview

Open the repository in VS Code and use Live Server to view the pages in a browser.

## Notes

- The temple album uses mobile-first CSS.
- The navigation collapses into a hamburger menu on smaller screens.
- The gallery changes from one column on mobile to two columns on medium screens and three columns on large screens.
